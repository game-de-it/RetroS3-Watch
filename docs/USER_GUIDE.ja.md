# ユーザー向け操作マニュアル

## 基本の画面遷移

```text
時計 -> ランチャー -> ROMブラウザー -> MSX
              |                 |
              +-> 設定       +-> MSX1 / MSX2 / MSX2+
              +-> Wi-Fi転送
              +-> 画面テスト
```

- 本体の**BOOT**でランチャーを開き、ブラウザーやゲーム画面から戻ります。
- **PWR**でAMOLEDの消灯／復帰を切り替えます。PWRはゲーム終了とは異なります。
- ランチャーとROM一覧はタッチ操作です。

## ソフトの起動

1. `ROM BROWSER`を開きます。
2. タイトルに合わせて`MODEL`をMSX1・MSX2・MSX2+のいずれかに設定します。
3. `.rom`、`.dsk`、`.cas`をタップします。

既定はMSX2です。同梱C-BIOSは主にカートリッジROM向けです。ディスクや
テープは、同梱されていない対応BIOS環境が必要な場合があります。

## コントローラー操作

検証済みはKモードの8BitDo Micro（表示名`80EL`）です。

| ボタン | ゲーム中 | メニュ／キーボード |
|---|---|---|
| 十字キー | MSXジョイスティック | 選択・カーソル移動 |
| A | FIRE A | 決定・キー入力 |
| B | FIRE B | 戻る・閉じる・再開 |
| START | ソフトウェアキーボードの表示／非表示 | — |
| SELECT | MSXメニューの表示／非表示 | — |
| L2 | 音量／輝度変更用 | キーボードでSHIFT画面切り替え |

方向キーを短く押すと1項目移動し、長押しすると少し待ってからリピートします。

## 音量と輝度

ソフトキーボード以外で**L2**を押しながら：

- 上：音量 +5%
- 下：音量 -5%
- 左：輝度 -10%
- 右：輝度 +10%

長押しで一定時間後にリピートします。組み合わせ中の方向入力はゲームへ渡されません。
値は操作終了後に保存されます。`SETTINGS`の大きなタッチボタンでも変更できます。

## ソフトキーボード

エミュレーション中に**START**を押します。1画面に4列を表示し、左右移動で
12列の3バンクを切り替えます。

- A：選択キーの入力またはモディファイアの切り替え
- B：キーボードを閉じる
- L2：SHIFT記号画面の切り替え
- `SHF`：L2の画面上代替
- `CTRL`、`GRAPH`：トグル式

日本語MSX配列の印字記号、F1〜F5、HOME、SELECT、CAPS、STOP、
編集キー、カーソルキーを入力できます。`CNT`でキーボードを閉じます。

`.cas`をマウントした場合の一般的なBASICコマンド：

```text
RUN"CAS:"
```

この操作にはカセット対応BASIC環境が必要で、同梱C-BIOSだけでは完全対応しません。

## MSXメニュー

エミュレーション中に**SELECT**を押すと、ゲームが一時停止してメニューが開きます。

- `RESUME`：ゲームに戻る
- `LOAD STATE` / `SAVE STATE`：タイトルごとの3スロット
- `CHANGE DISK A` / `CHANGE DISK B`：選んだドライブのDSKを交換
- `REWIND TAPE`：挿入中のカセットを巻き戻す
- `RESET`：現在のMSXをリセット
- `QUIT`：エミュレーションを終了してランチャーへ戻る

Bで前の画面に戻ります。長いディスク名はカーソルを合わせると横にスクロールします。

## Wi-Fi転送

導入マニュアルに従ってUSBからWi-Fi認証情報を保存します。`Wi-Fi UPLOAD`を開き、
表示されたHTTPアドレスへ同一LANのブラウザーからアクセスします。

転送先と1ファイルを選びます。端末はmicroSDへ書き込み、SHA-256再読み出しを
確認してから既存ファイルを置き換えます。画面を離れるとWi-Fiを停止します。

## セーブデータ

- 保存先はmicroSDの`/msx/states`です。
- タイトルと機種ごとに別スロットです。
- `.rss`の復元には、交換後のディスクも含め、保存時と同じBIOSとメディアが必要です。
  v0.1.0のステートとは互換性がありません。
- 一時ファイルを書き、可能な場合は直前の状態をバックアップとして残します。
- SAVE/LOAD中にmicroSDを抜いたり電源を切ったりしないでください。

## 表示動作

コールドブート後から100%描画で動作します。実機のUSASデモで安定時は約59.4fpsでした。
起動や場面の切り替えでは表示頻度が下がる場合があります。メニューとキーボードは
時計側のオーバーレイで描画します。

`60FPS TEST`と`DISPLAY TEST`は開発・診断用画面です。BOOTで戻ります。

## トラブルシューティング

### カートリッジが起動しない

- 機種を切り替えます。必要に応じて[コアガイド](INDEPENDENT_MSX.ja.md)の手順でマッパーを指定します。
- 有効なMSXカートリッジイメージか確認します。
- C-BIOSはすべてのタイトルと互換ではありません。

### ディスクやテープが起動しない

カセットには対応するシステムBIOS、読み取り専用のDSKには加えてWD2793互換の
`DISK.ROM`が必要です。ファイル名を[導入マニュアル](INSTALLATION.ja.md)で確認します。

### コントローラーを検出しない

- 8BitDo MicroをKモードにします。
- 他のホストとの接続を解除します。
- コントローラーと時計を再起動し、`80EL`検出を数秒待ちます。

### Wi-Fiに接続できない

- 2.4GHzの通信可能なネットワークを使います。
- USBから認証情報を再登録します。
- PCと時計が同一LANにいることを確認します。

### ステートを読み込めない

保存時と同じタイトル、機種、BIOSセット、メディアを使います。交換後に保存した
ディスクは、復元前に同じドライブへ入れてください。以前の状態を残す場合は別スロットへ保存します。
