# microSD starter files / microSDスターターファイル

Copy the contents of this directory to the root of a FAT32 microSD card.
The included `msx/bios` files are C-BIOS 0.29, renamed to the filenames used
by the firmware. The MSX2+ profile uses `MSX2P.ROM`, `MSX2PEXT.ROM`, and
the optional startup logo `CBIOS2P.ROM`.

FAT32で初期化したmicroSDカードのルートへ、このディレクトリの内容をコピーして
ください。`msx/bios`はC-BIOS 0.29を本ファームウェアのファイル名に合わせた
ものです。MSX2+では `MSX2P.ROM`、`MSX2PEXT.ROM`、
任意の起動ロゴ `CBIOS2P.ROM` を使用します。

Add your legally obtained game media to `msx/roms`. Do not commit it to a
public repository. C-BIOS is suitable mainly for cartridge ROM software;
disk, cassette and BASIC use may require legally obtained proprietary system
ROMs that are not supplied here.

利用権を持つゲームメディアは`msx/roms`に追加します。公開リポジトリへは
コミットしないでください。
